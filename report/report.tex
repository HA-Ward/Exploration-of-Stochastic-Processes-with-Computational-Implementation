\section{Random Walks}
\subsection{Mathematical Definition}
A random walk is simply a path created by a series of random steps. We would define a  1 dimensional random walk process to go up by $1$ with a probability of $p$ and down by $1$ with a probability of $q$. This can be written formally as, \[ X_{n+1} = \begin{cases} X_n+1 &\text{with probability} \hspace{2mm}p,\\X_n-1 &\text{with probability} \hspace{2mm}q.\end{cases}
\]
Or alternatively, \[ X_n = X_0 + \sum^n_{i=1}Z_i, \hspace{4mm} \text{where} \hspace{4mm} Z_i = \begin{cases}
    1  &\text{with probability} \hspace{2mm}p,\\
    -1  &\text{with probability}\hspace{2mm} q.
\end{cases}\].

\subsection{Theoretical Properties}
The expectation of a random walk is defined as \[E[X_n] = X_0+n(p-q).\]
This can be proved using the second definition for a random walk by taking the expectation of $X_n$ \[E[X_n] = E[X_0] +E\Bigg[\sum^n_{i=1}Z_i\Bigg] \Rightarrow E[X_n] = X_0 + \sum^n_{i=1}E[Z_i]\]
and since $\mathbb{P}(Z_i = 1)=p \hspace{2mm} \text{and} \hspace{2mm} \mathbb{P}(Z_i=-1) = q$ we have, \[E[Z_i] = p- q\]
giving \[E[X_n] = X_0 + \sum^n_{i=1}(p - q) = X_0 + n(p-q).\]




\noindent\\The variance of a random walk is defined as \[Var[X_n] = 4npq.\]
Since $Var[X_0]=0$, This can be simply proved by taking the variance of $X_n$ \[Var[X_n] = Var[X_0] + \sum^n_{i=1}Var[Z_i] = nVar[Z_1]\]
and with $E[Z_1^2]= p+q$
\begin{align*}
Var[Z_1] &= E[Z_1^2]-E[Z_1]^2,\\
&= (p+q)-(p-q)^2,\\
&= (p+q) - (p^2-2pq-q^2),\\
&= p(1-p) + q(1-q) + 2pq,\\
&= pq + pq + 2pq=4pq,\\
Var[X_n] &= nVar[Z_1] = 4npq.
\end{align*}

\subsection{Computational Implementation}
The random walks were simulated by generating independent Bernoulli trials at each step, with a probability $p$ of going up by 1 and $1-p$ going down by 1. The results from these Bernoulli trials were cumulatively summed to create the path. The simulation can be repeated for a lage number of independent paths allowing for us to estimate quantities for expectation and variance and see how they compare with the theoretical results.

\end{align*}

This is because the mean is estimated by averaging outcomes directly whereas variance is estimated by averaging the squared deviation from the mean. Squaring amplifies the influence of any walk that travels far from the mean and explains why for our $n=20$ simulation the estimated variance is much larger than the theoretical since it contained a relatively extreme final positions.

\section{Gamblers Ruin}
\subsection{Problem Formulation}
Player A is playing against Player B, Player A starts with £$a$ and Player B starts with £$b$ where $m = a+b$ is the total amount of money. At each step in the game each player bets £$1$ where Player A wins £$1$ with probability $p$ and loses with probability $q$. There game continues until either player goes bankrupt. We can represent this a stochastic process \[X_{n+1} = \begin{cases}
    X_n + 1 &\text{with probabilty }p \text{ if } 1\leq X_n \leq m-1,\\
    X_n -1 &\text{with probability }q \text{ if } 1\leq X_n \leq m-1,\\
    0 &\text{if }X_n = 0,\\
    m &\text{if }X_n = m.
\end{cases}\] This is the same as a random walk but with absorbing barriers at $X_n=0$ and $X_n = m$.
\subsection{Analytical Solution}
First lets solve for the probability of ruin, that is the probability of player A going bankrupt. We can write 
\begin{align*}
\mathbb{P}(\text{Ruin}) &= \mathbb{P}(\text{win first round})\mathbb{P}(\text{Ruin} \mid \text{win first round}) + \mathbb{P}(\text{lose first round})\mathbb{P}(\text{Ruin} \mid \text{lose first round})\\
&=p\mathbb{P}(\text{Ruin} \mid \text{win first round}) + q\mathbb{P}(\text{Ruin} \mid \text{lose first round})
\end{align*}
\noindent
From the property of Markov processes we know that $\mathbb{P}(\text{Ruin} \mid \text{lose first round})$ and $\mathbb{P}(\text{Ruin} \mid \text{win first round})$ are the same as $\mathbb{P}(\text{Ruin})$ just with $\pm1$ starting points, allowing us to write probability or ruin as \[r_i = pr_{i+1} + qr_{i-1}.\]
giving the linear difference, \[pr_{i+1}-r_i+qr_{i-1}=0 \qquad \text{subject to} \qquad r_0=1,\, r_m=0. \]
\noindent
by solving the difference equation with $a$ as the start point and $\rho = q/p$, the solution for the probability of ruin is \[ r_a = \begin{cases}
    \frac{\rho^a - \rho^m}{1-\rho^m} &\text{if }\rho \ne 1,\\
    1-\frac{a}{m} &\text{if }\rho = 1.
\end{cases}\]

similarly we can solve for expected duration of game, \begin{align*}
    E[\text{duration}] &= \mathbb{P}(\text{win first round})E[\text{duration} \mid \text{win first round}] + \mathbb{P}(\text{lose first round})E[\text{duration} \mid \text{lose first round}]\\
    &= pE[\text{duration} \mid \text{win first round}] + qE[\text{duration} \mid \text{lose first round}]\\
    d_i &= p(1+d_{i+1}) + q(1+d_{i-1})
\end{align*}
\noindent
The important difference is that $E[\text{duration} \mid \text{win first round}] = 1+d_{i+1}$ because the round itself takes $1$ time step. Again we can rearrange to form the difference equation \[pd_{i+1} - d_i +qd_{i-1} = -1 \quad \text{subject to} \quad d_0=0, \, d_m = 0.\]

and solving this inhomogeneous difference equation we obtain 
\[d_a = \begin{cases}
    \frac{1}{q-p}(a-m \frac{1 - \rho^a}{1-\rho^m}) &\text{if } \rho \ne 1,\\
    a(m-a) &\text{if } \rho = 1.
\end{cases}
\]

Figure~(\ref{fig:sim error}) includes 2 plots, the plot on the left shows how the ratio of paths that become ruined change with increase n and the figure on the right shows absolute error. At first this result might not be what you expected as after the first few thousand number of paths we don't really observe a convergence, instead it seems to look like a white noise process.

This can be explained since we can treat each path as an independent Bernoulli trial (ruined, not ruined), with variance $p(1-p)$. Since our simulated ratio $\hat{p}$ is the average of $n$ trials its variance is $p(1-p)/n$ and therefore the standard error is $SE[\hat{p}] = \sqrt{p(1-p)/n}$. The standard error is proportional to $1/\sqrt{n}$ this is why from $n =2000$ to $n = 10000$ a $\times5$ increase in $n$ we only observe a $1/\sqrt{5} \approx2.2$ shrinkage in error.

On the figure in the right I included a plot of standard error since it gives the theoretical scale of which the error should fluctuate around.

\subsection{Theory vs Simulation}
We have looked at how probability of ruin can be calculated and simulated, now lets look at solving duration. Using the same variables $m=50$, $p=0.51$ and $a=20$ as last time we can calculate the expected duration \[d_{20} = \frac{1}{0.49-0.51}(20-50\times\frac{1-\frac{49}{51}^{20}}{1-\frac{49}{51}^{50}})=592.2.\]

Now we can calculate the mean duration from simulating $100,000$ paths, Figure~(\ref{fig:hist gruin}) shows the mean duration and compares it with the theoretical expected duration. More importantly it shows the shape of its distribution.

\begin{figure}[h]
    \centering
    \includegraphics[width=0.5\linewidth]{figures//Gamblers_ruin/hist steps gruin.png}
    \caption{Histogram of total steps}
    \label{fig:hist gruin}
\end{figure}

Whilst having the equation to work out theoretical expected duration is handy especially as it matches the simulated value, in practice it would be much better to have the distribution associated with duration. That being said this distribution doesn't follow any standard binomial, poisson, normal or gamma distributions. Instead we can use python to track the probability of being at each position over time, splitting each step by $p$ and $q$ until it records how much land on $0$ and $m$ at each step. This gives the exact PMF for duration of the game shown in Figure~(\ref{fig:sim vs exact}).

\begin{figure}
    \centering
    \includegraphics[width=1\linewidth]{figures//Gamblers_ruin/sim dist vs pmf.png}
    \caption{Simulated distribution vs probabilty mass function}
    \label{fig:sim vs exact}
\end{figure}

The simulated paths appear to reinforce our method for calculating the exact PMF, this result is quite important as we can now find exact probabilities using this distribution instead of using just expected duration or probabilities from the simulated distribution. For example lets say we want to find the number of steps it would take for us to be $95\%$ confident that the game has finished we can use a search in python to find that it would take $1521$.

\noindent
Experimenting with values for $a$, $m$ and $p$ I was able create the PMF in Figure~(\ref{fig:pmf a = 10, m = 150}). This process is quite interesting as there is a relatively high probability of the game finishing early on as the start position of $10$ is very close to $0$, however because of the probability $p=0.525$ there is a drift that means the theoretical probability of ruin is only $0.448$.
