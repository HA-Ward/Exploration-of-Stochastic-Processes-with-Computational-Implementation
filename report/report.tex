\section{Random Walks}
\subsection{Mathematical Definition}
A random walk is simply a path created by a series of random steps. We would define a  1 dimensional random walk process to go up by $1$ with a probability of $p$ and down by $1$ with a probability of $q$. This can be written formally as, \[ X_{n+1} = \begin{cases} X_n+1 &\text{with probability} \hspace{2mm}p,\\X_n-1 &\text{with probability} \hspace{2mm}q.\end{cases}
\]
Or alternatively, \[ X_n = X_0 + \sum^n_{i=1}Z_i, \hspace{4mm} \text{where} \hspace{4mm} Z_i = \begin{cases}
    1  &\text{with probability} \hspace{2mm}p,\\
    -1  &\text{with probability}\hspace{2mm} q.
\end{cases}\].

\subsection{Theoretical Properties}
The expectation of a random walk is defined as \[E[X_n] = X_0+n(p-q).\]
This can be proved using the second definition for a random walk by taking the expectation of $X_n$ \[E[X_n] = E[X_0] +E\Bigg[\sum^n_{i=1}Z_i\Bigg] \Rightarrow E[X_n] = X_0 + \sum^n_{i=1}E[Z_i]\]
and since $\mathbb{P}(Z_i = 1)=p \hspace{2mm} \text{and} \hspace{2mm} \mathbb{P}(Z_i=-1) = q$ we have, \[E[Z_i] = p- q\]
giving \[E[X_n] = X_0 + \sum^n_{i=1}(p - q) = X_0 + n(p-q).\]




\noindent\\The variance of a random walk is defined as \[Var[X_n] = 4npq.\]
Since $Var[X_0]=0$, This can be simply proved by taking the variance of $X_n$ \[Var[X_n] = Var[X_0] + \sum^n_{i=1}Var[Z_i] = nVar[Z_1]\]
and with $E[Z_1^2]= p+q$
\begin{align}
Var[Z_1] &= E[Z_1^2]-E[Z_1]^2,\\
&= (p+q)-(p-q)^2,\\
&= (p+q) - (p^2-2pq-q^2),\\
&= p(1-p) + q(1-q) + 2pq,\\
&= pq + pq + 2pq=4pq,\\
Var[X_n] &= nVar[Z_1] = 4npq.
\end{align}

\subsection{Computational Implementation}
The random walks were simulated by generating independent Bernoulli trials at each step, with a probability $p$ of going up by 1 and $1-p$ going down by 1. The results from these Bernoulli trials were cumulatively summed to create the path. The simulation can be repeated for a lage number of independent paths allowing for us to estimate quantities for expectation and variance and see how they compare with the theoretical results.

Using the equations for variance and expectation we obtain theoretical values: \begin{align*}
    E[X_{300}] &= 0+ 300\times(0.6-0.4)=60\\
    Var[X_{300}] &= 4\times 300 \times 0.6 \times 0.4 = 288
\end{align*}
We can see that as $n$ increases the estimated values for expectation and variance become more accurate, interestingly our estimations for expectation were all pretty close to the theoretical value even with small $n$ whilst the estimated variance was a lot less accurate. This is because the mean is estimated by averaging outcomes directly whereas variance is estimated by averaging the squared deviation from the mean. Squaring amplifies the influence of any walk that travels far from the mean and explains why for our $n=20$ simulation the estimated variance is much larger than the theoretical since it contained a relatively extreme final positions.

\section{Gamblers Ruin}
\subsection{Problem Formulation}
Player A is playing against Player B, Player A starts with £$a$ and Player B starts with £$b$ where $m = a+b$ is the total amount of money. At each step in the game each player bets £$1$ where Player A wins £$1$ with probability $p$ and loses with probability $q$. There game continues until either player goes bankrupt. We can represent this a stochastic process \[X_{n+1} = \begin{cases}
    X_n + 1 &\text{with probabilty }p \text{ if } 1\leq X_n \leq m-1,\\
    X_n -1 &\text{with probability }q \text{ if } 1\leq X_n \leq m-1,\\
    0 &\text{if }X_n = 0,\\
    m &\text{if }X_n = m.
\end{cases}\] This is the same as a random walk but with absorbing barriers at $X_n=0$ and $X_n = m$.
