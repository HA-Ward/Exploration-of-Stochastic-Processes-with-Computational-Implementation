\section{Random Walks}
\subsection{Mathematical Definition}
A random walk is a stochastic process constructed from a sequence of random increments. We would define a one-dimensional simple random walk process to go up by $1$ with a probability of $p$ and down by $1$ with a probability of $q$. This can be written formally as, \[ X_{n+1} = \begin{cases} X_n+1 &\text{with probability} \hspace{2mm}p,\\X_n-1 &\text{with probability} \hspace{2mm}q.\end{cases}
\]
Or alternatively, \[ X_n = X_0 + \sum^n_{i=1}Z_i, \hspace{4mm} \text{where} \hspace{4mm} Z_i = \begin{cases}
    1  &\text{with probability} \hspace{2mm}p,\\
    -1  &\text{with probability}\hspace{2mm} q.
\end{cases}\].

\subsection{Theoretical Properties}
The expectation of a random walk is defined as \[E[X_n] = X_0+n(p-q).\]
This can be proved using the second definition for a random walk by taking the expectation of $X_n$ \[E[X_n] = E[X_0] +E\Bigg[\sum^n_{i=1}Z_i\Bigg] \Rightarrow E[X_n] = X_0 + \sum^n_{i=1}E[Z_i]\]
and since $\mathbb{P}(Z_i = 1)=p \hspace{2mm} \text{and} \hspace{2mm} \mathbb{P}(Z_i=-1) = q$ we have, \[E[Z_i] = p- q\]
giving \[E[X_n] = X_0 + \sum^n_{i=1}(p - q) = X_0 + n(p-q).\]




\noindent\\The variance of a random walk is defined as \[Var[X_n] = 4npq.\]
Since $Var[X_0]=0$, This can be simply proved by taking the variance of $X_n$ \[Var[X_n] = Var[X_0] + \sum^n_{i=1}Var[Z_i] = nVar[Z_1]\]
and with $E[Z_1^2]= p+q$
\begin{align*}
Var[Z_1] &= E[Z_1^2]-E[Z_1]^2,\\
&= (p+q)-(p-q)^2,\\
&= (p+q) - (p^2-2pq-q^2),\\
&= p(1-p) + q(1-q) + 2pq,\\
&= pq + pq + 2pq=4pq,\\
Var[X_n] &= nVar[Z_1] = 4npq.
\end{align*}

\subsection{Computational Implementation}
The random walks were simulated by generating independent Bernoulli trials at each step, with a probability $p$ of going up by 1 and $1-p$ going down by 1. The results from these Bernoulli trials were cumulatively summed to create the path. The simulation can be repeated for a large number of independent paths allowing for us to estimate quantities for expectation and variance and see how they compare with the theoretical results.

\section{Gambler's Ruin}
\subsection{Problem Formulation}
Player A is playing against Player B, Player A starts with £$a$ and Player B starts with £$b$ where $m = a+b$ is the total amount of money. At each step in the game each player bets £$1$ where Player A wins £$1$ with probability $p$ and loses with probability $q$. The game continues until either player goes bankrupt. We can represent this as a stochastic process \[X_{n+1} = \begin{cases}
    X_n + 1 &\text{with probability }p \text{ if } 1\leq X_n \leq m-1,\\
    X_n -1 &\text{with probability }q \text{ if } 1\leq X_n \leq m-1,\\
    0 &\text{if }X_n = 0,\\
    m &\text{if }X_n = m.
\end{cases}\] This is the same as a random walk but with absorbing barriers at $X_n=0$ and $X_n = m$.
\subsection{Analytical Solution}
First let's solve for the probability of ruin, that is the probability of player A going bankrupt. We can write 
\begin{align*}
\mathbb{P}(\text{Ruin}) &= \mathbb{P}(\text{win first round})\mathbb{P}(\text{Ruin} \mid \text{win first round}) + \mathbb{P}(\text{lose first round})\mathbb{P}(\text{Ruin} \mid \text{lose first round})\\
&=p\mathbb{P}(\text{Ruin} \mid \text{win first round}) + q\mathbb{P}(\text{Ruin} \mid \text{lose first round})
\end{align*}
\noindent
From the property of Markov processes we know that $\mathbb{P}(\text{Ruin} \mid \text{lose first round})$ and $\mathbb{P}(\text{Ruin} \mid \text{win first round})$ are the same as $\mathbb{P}(\text{Ruin})$ just with $\pm1$ starting points, allowing us to write probability of ruin as \[r_i = pr_{i+1} + qr_{i-1}.\]
giving the linear difference, \[pr_{i+1}-r_i+qr_{i-1}=0 \qquad \text{subject to} \qquad r_0=1,\, r_m=0. \]
\noindent
by solving the difference equation with $a$ as the start point and $\rho = q/p$, the solution for the probability of ruin is \[ r_a = \begin{cases}
    \frac{\rho^a - \rho^m}{1-\rho^m} &\text{if }\rho \ne 1,\\
    1-\frac{a}{m} &\text{if }\rho = 1.
\end{cases}\]

similarly, we can solve for expected duration of game, \begin{align*}
    E[\text{duration}] &= \mathbb{P}(\text{win first round})E[\text{duration} \mid \text{win first round}] + \mathbb{P}(\text{lose first round})E[\text{duration} \mid \text{lose first round}]\\
    &= pE[\text{duration} \mid \text{win first round}] + qE[\text{duration} \mid \text{lose first round}]\\
    d_i &= p(1+d_{i+1}) + q(1+d_{i-1})
\end{align*}
\noindent
The important difference is that $E[\text{duration} \mid \text{win first round}] = 1+d_{i+1}$ because the round itself takes $1$ time step. Again we can rearrange to form the difference equation \[pd_{i+1} - d_i +qd_{i-1} = -1 \quad \text{subject to} \quad d_0=0, \, d_m = 0.\]

and solving this inhomogeneous difference equation we obtain 
\[d_a = \begin{cases}
    \frac{1}{q-p}(a-m \frac{1 - \rho^a}{1-\rho^m}) &\text{if } \rho \ne 1,\\
    a(m-a) &\text{if } \rho = 1.
\end{cases}
\]

\section{Markov Chains}

\subsection{Transition Probabilities and Matrices}
A Markov chain is a series of random variables $X_0, X_1,X_2,...$ taking values from a state space $S$ whilst satisfying the Markov property. Which is formally written \[\mathbb{P}(X_{n+1}=j \mid X_n=i,X_{n-1},...,X_0)=\mathbb{P}(X_{n+1}=j \mid X_n=i).\]
Or in words, given the present state the future is independent of the past. Recall that we used this property in solving gambler's ruin, however we used it to condition the problem on its first step and then solving the difference equation. Whilst this method works cleanly for the gambler's ruin problem, using transition probabilities/matrices gives an explicit method that works with any transition structure or number of states.

In the previous examples we also only considered a specific start point, but we could pick a start point according to some distribution $\lambda_i =\mathbb{P}(X_0=i)$. Now consider Figure~(\ref{fig:3 state td}) a 3-state Markov chain with state space $S=\{0,1,2\}$ and transition matrix \[P = \begin{pmatrix}
    p_{00}&p_{01}&p_{02}\\
    p_{10}&p_{11}&p_{12}\\
    p_{20}&p_{21}&p_{22}
\end{pmatrix}=\begin{pmatrix}
    0&0.3&0.7\\
    0.4&0&0.6\\
    0.5&0.5&0
\end{pmatrix}.\]

\caption{three state transition diagram}

\noindent
To find the probability of landing on a state $j$ after $n$ steps we can write \[ p_{ij}(n) = \mathbb{P}(X_n=j \mid X_0 = i).\]
Where $p_{ij}(n)$ is the $(i,j)th$ entry of the matrix $P^n$. So if we wanted to find the probability of being in state $1$, three steps after starting in state $2$ we would only need to calculate the matrix $P^3$ which is a non-trivial process using computation. With \[P^3 = \begin{pmatrix}
    0.23 &0.231&0.539\\
 0.308&0.23 &0.462\\
 0.385&0.385&0.23 
\end{pmatrix}\]
looking at the $(2,1)$ entry we can see that the probability would be $0.385$. However when considering a start distribution $\lambda_i$ we instead say that that the probability $\mathbb{P}(X_n=j)$ is the $jth$ entry in the row vector of probabilities given by $\lambda P^n$. So if we instead considered the start distribution of \[ \lambda_i =\mathbb{P}(X_0 =i)=\begin{cases}
    0.2& \text{if }i=0\\
    0.4& \text{if }i=1\\
    0.4& \text{if }i=2
\end{cases} \hspace{10mm}\lambda = \begin{pmatrix}
    0.2&0.4&0.4
\end{pmatrix}\]
we now have \[\lambda P^3 = \begin{pmatrix}
    0.3232&0.2922&0.3846
\end{pmatrix}.\]
So if we still wanted to know the probability of ending on $1$ whilst knowing only the start distribution, we get a probability of $0.2922$.

\subsection{Gambler's Ruin as a Markov Chain}
Let's revise the gambler's ruin problem using the same values $m =50$, $p=0.51$ and $a = 20$ but instead explicitly solving using Markov chains instead of using the formulas derived by solving difference equations. We can do this using a $51\times51$ transition matrix where for every $ith$ row entry $(i,i-1)=1-p$ and $(i,i+1) = p$ apart from row $0$ and $m$ which have entries $(0,0) = 1$ and $(m,m) = 1$ respectively. Which will look like this: \[P = \begin{pmatrix}
    1&0&0&\cdots&0&0&0\\
    0.49&0&0.51&\cdots&0&0&0\\
    0&0.49&0&\cdots&0&0&0\\
    \vdots&\vdots&\vdots&\ddots&\vdots&\vdots&\vdots\\
    0&0&0&\cdots&0&0.51&0\\
    0&0&0&\cdots&0.49&0&0.51\\
    0&0&0&\cdots&0&0&1
\end{pmatrix}\]

Using the transition matrix we can calculate the probability of being in any state at any step in time, which is particularly useful for finding the probability of ruin at any step you want. The left plot in Figure~(\ref{fig:cpruin and cdf duration}) was quickly computed by calculating the probability of being in the ruined state at every step until 5000. As you can see in the plot it converges at 0.3631 which is the probability of ruin calculated using the equation from the last section.

\section{Poisson processes}
\subsection{Defining a Poisson Process}
Previously we have been working on stochastic processes in discrete space $S = \mathbb{Z}$ and discrete time steps. Poisson processes still exist in a discrete space, however with continuous time. Picture a walk that can only move upwards but instead of just moving at each fixed step, there is a distribution deciding on when each step will be. This in fact is one of the ways we can define the Poisson process. More officially let $T_1,T_2,T_3,...$ be i.i.d. random variables of time between each step with $T_i \sim \text{Exponential}[\lambda]$ then \[ X(t) = \begin{cases}
    0 &\text{for }0\leq t \leq T_1, \\
     1 &\text{for }T_1\leq t \leq T_1 + T_2, \\
      2 &\text{for }T_1 + T_2\leq t \leq T_1 + T_2 +T_3, \\
      \text{and so on.}
\end{cases}\]
\noindent
Figure~(\ref{fig:visualization of poisson process}) shows a visualization of what this process would look like if we had a rate of $\lambda = 0.5$ and max time of $10$.

\begin{figure}[h]
    \centering
    \includegraphics[width=0.5\linewidth]{figures//Poisson processes/Visualization of poisson process.png}
    \caption{Visualization of Poisson process}
    \label{fig:visualization of poisson process}
\end{figure}

We can also define a Poisson process using Poisson increments. That is a stochastic process $X(t)$ is a Poisson process if: \begin{enumerate}
    \item $X(0) = 0$
    \item $X(t+s) - X(t) \sim Po(\lambda s)$ for all $s, t > 0$
    \item $X(t_2) - X(t_1)$ and $X(t_4) - X(t_3)$ are independent for all $t_1 \leq t_2 \leq t_3 \leq t_4$
\end{enumerate}

This definition and the first definition are equivalent, however using this definition we can easily work out the theoretical probability of a number of events happening in a given time. Whilst the first definition makes it easy to simulate a sample path whilst also being able to solve problems about waiting times.

\section{Brownian Motion}
\subsection{Definitions and Properties}
Continuing with continuous time let's introduce Brownian motion. Brownian motion is a continuous-time and continuous state-space Markov process. A stochastic process $B(t)$ is defined as Brownian motion if it satisfies:
\begin{enumerate}
    \item $B(0) = 0$ and $B(t)$ is a continuous function of $t$
    \item independent increments: for any $0 < t_1 < t_2 < t_3 <  t_4$ the increments \[B(t_2) - B(t_1)\text{ and } B(t_4) - B(t_3)\] are independent random variables.
    \item stationary Gaussian increments: for every time $t$ and time increment $\Delta t$, \[B(t+\Delta t) - B(t) \sim N(0, \sigma ^2 \Delta t)\] where $\sigma  > 0$ is the volatility parameter.
\end{enumerate}

At this stage it is also important to introduce the Gaussian random walk, a discrete time continuous space Markov process. Earlier we defined a simple random walk as \[ X_n = X_0 + \sum^n_{i=1}Z_i, \hspace{4mm} \text{where} \hspace{4mm} Z_i = \begin{cases}
    1  &\text{with probability} \hspace{2mm}p,\\
    -1  &\text{with probability}\hspace{2mm} q.
\end{cases}\].
The Gaussian random walk follows a similar process however instead of using the step distribution $Z_i$ with $\pm 1$ for probabilities $p$ and $q$, it uses independently distributed $\epsilon_i \sim N(0, \sigma ^2)$. Which looks like \[ X_n = X_0 + \sum^n_{i=1}\epsilon_i, \hspace{4mm} \text{where} \hspace{4mm} \epsilon_i\sim N(0, \sigma ^2). \]

Comparing the definitions of Brownian motion and Gaussian random walks, they both use the same incremental structure with independent and stationary Gaussian increments. They only differ in their time and state space with Gaussian random walks defined in discrete time $n \in \{0,1,2,\dots \}$ with fixed variance $\sigma ^2$ and Brownian motion defined in continuous time with $t \geq 0$ and an increment variance $\sigma^2 \Delta t$ scaling with size of the time gap. Therefore discretizing Brownian motion onto a fixed time grid $\Delta t$ gives a Gaussian random walk with step variance $\sigma ^2 \Delta t$. This is the exact method we can use to simulate Brownian motion.

More generally, even non-Gaussian i.i.d. steps converge to Brownian motion in the limit, this is the content of Donsker's invariance principle which states, let $\{X_1,X_2, X_3,\dots \}$ be i.i.d. random variables with $E[X_i] = 0$ and $Var[X_i] = 1$. Define the random walk after n steps, \[ S_n = X_1+X_2+\cdots + X_n.\] Normalise this walk by defining $B_n(t)$ for $t \geq 0$ as \[B_n(t) = \frac{S_{[nt]}}{\sqrt{n}}\] where $[nt]$ is the largest integer less than $nt$. Donsker's invariance principle states that $B_n$ converges in distribution to a standard Brownian motion as $n\rightarrow\infty$.

Figure~(\ref{fig:Brownian motion delta t}) shows this visually and as $\Delta t$ decreases we see a clearer illustration of what Brownian motion looks like. When using Gaussian random walks at each point, there is no approximation error, they match the Brownian motion exactly, the only discrepancy is between the grid points but we know this vanishes as the grid is refined, so when using Gaussian random walks to simulate Brownian motion the key takeaway is that it's exact at the grid points but only an estimate between them.

\begin{figure}
    \centering
    \includegraphics[width=0.5\linewidth]{figures//Brownian_motion/bm vs grw.png}
    \caption{Image showing change in increment size $\Delta t$ for the same Brownian motion}
    \label{fig:Brownian motion delta t}
\end{figure}


We can model probability by using the conditional distribution $Y= B(t)$ given $X = B(s)$, \[ [Y \mid X=x] \sim N(x, \sigma ^2 (t-s)) \qquad\text{for} \quad t > s\] with a probability density function of \[p(y,t \mid x) = \frac{1}{\sqrt{2\pi \sigma ^2 (t-s)}} e^{-\frac{1}{2}\frac{(y-x)^2}{\sigma ^2 (t-s)}}.\]
Also note that for any Brownian motion $B(t)$, $E[B(t)] = 0$ and $Var[B(t)] = \sigma^2 t$.

We can see that for all time $t$ the expectation of $B(t)$ is $0$.

We established earlier $B(t) \sim N(0, \sigma^2 t)$ with PDF $p(y, t \mid x)$, now let's introduce the diffusion equation that the PDF satisfies: \[ \frac{\partial p}{\partial t} = \frac{1}{2} \sigma^2 \frac{\partial ^2 p}{\partial y^2}.\]
At the peak $y= 0$ the shape of the curve is locally concave so $\frac{\partial^2 p}{\partial y^2} < 0$ and therefore $\frac{\partial p}{\partial t} < 0$, so the peak is falling which is exactly what we see in the plot. Similarly at the tails which are convex we have $\frac{\partial^2 p}{\partial y^2} > 0$ so $\frac{\partial p}{\partial t} > 0$, telling us that the ends are rising.

It is worth noting that the diffusion equation isn't really necessary for standard Brownian motion as solving the PDE would give us the same PDF as defining Brownian motion by gaussian increments. The diffusion equation is mostly useful for its generality as later it could be used for solving more complex equations.

\subsection{Two Boundary Hitting Times for Brownian Motion}
let's consider a Brownian motion with two boundaries with one at $0$ and the other at $m$, where we want to know the expected time before hitting a boundary and the probability of hitting each boundary. In essence this is a variation of Gambler's ruin problem however in continuous time and space state.
\begin{figure}[h!]
    \centering
    \includegraphics[width=0.45\linewidth]{figures/Brownian_motion/G_ruin_continuous.png}
    \caption{Gambler's ruin in continuous time}
    \label{fig:g_ruin_cont}
\end{figure}

\noindent{}Figure~(\ref{fig:g_ruin_cont}) shows a simulated realization of a Brownian motion in a gambler's ruin problem with start position $a = 20$ and barriers at $m= 40$ and $0$, the final time $T$ was estimated by linear interpolation of the path between the last position inside the barriers and first position outside them.

Like before let's first derive formula for probability of ruin and expected duration, before this let's introduce martingales. 

Martingales are essentially just stochastic processes where the expected future position is the position it is in currently, \[ E[X_{t+n} \mid X_0, \dots, X_t] = X_t.\]
Brownian motion is also a martingale, since its increments have zero conditional expectation..

We now consider Brownian motion started at $a$, so that $B_0=a$, and fix 2 boundaries at $0$ and $m$. Let's define the stopping time \[T = \text{inf} \{t \ge 0: B_t = 0 \text{ or } B_t = m\},\] the first time the
Brownian motion hits either boundary. We want \[p(a) = \mathbb{P}(B_t = 0 \mid B_0 = a),\] the probability of hitting 0 before m. From the property of Martingales we know \[ E[B_T] = E[B_0] = a\] and using the fact that there can only be two outcomes $B_T = 0$ with probability $p(a)$ and $B_T = m$ with probability $1 - p(a)$ we can solve for $p(a)$,

\begin{align*}
    E[B_T] = 0 \times p(a) + m \times (1-p(a)) &= a \\
     m(1-p(a)) &= a \\
    p(a) = 1- \frac{a}{m} = \frac{m-a}{m}.
\end{align*}
To solve for expected duration we need to use a clever trick since $E[B_T]$ alone can't give us $E[T]$ since $B_t$ carries no information on time elapsed, so in order to solve $E[T]$ we need a martingale that explicitly involves t, in this case we will use the martingale $X_t = B^2_t -t$. To prove $X_t$ is in fact a martingale we need to make sure \[E[B_{t+n}^2 -(t+n) \mid B_0, \dots, B_t] = B_t^2 -t\] is satisfied. Let \[ B_{t+n} = B_t + \Delta, \quad \text{where} \quad \Delta = B_{t+n} - B_t \sim N(0,n) \text{ is independent of } B_0, \dots, B_t.\] Then, \[B_{t+n}^2 = B^2_t + 2B_t\Delta + \Delta^2 \] and by taking expectations with $E[\Delta] = 0$ and $E[\Delta^2] = n$ we get, \[E[B^2_{t+n} \mid B_0, \dots, B_t] = B^2_t + 2B_t \cdot E[\Delta] + E[\Delta^2] = B^2_t + n\] so, \[E[B_{t+n}^2 -(t+n) \mid B_0, \dots, B_t] = B_t^2 +n - (t + n) =B_t^2 -t.\] This confirms that $X_t = B_t^2 -t$ satisfies the martingale property. Therefore \begin{align*}
    &E[X_T] = E[X_0] \\
    &E[B^2_T-T] = E[B_0^2 - 0] = a^2 \\
    &E[B^2_T] - E[T] = a^2.
\end{align*}
Using the ruin probability from before we can compute $E[B^2_T]$ as \[E[B^2_T] = 0^2 \times p(a) +m^2 \times (1-p(a)) = m^2 \times \frac{a}{m} = am\] and finally we can substitute into $E[B_T^2] - E[T] = a^2 $ to solve for $E[T]$ where we obtain \[E[T] = am-a^2 = a(m-a).\]

From the formulas we have derived there is a linear relationship between probability of ruin and start position and a quadratic relation between expected duration and start position. Before verifying this computationally let's first investigate how the accuracy of these formulas changes with sample size.
